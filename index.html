Gestion de bibliothèque

Organiser les livres, les auteurs et le suivi des emprunts dans une application de bureau.

C#WinFormsSQL ServerArchitecture 3 tiers
Fonctionnalités, architecture et code ↗

Objectif : gérer le catalogue et suivre les emprunts depuis une interface Windows Forms.

  • Modèles Livre, Auteur et Emprunt; base SQL avec clés étrangères.
  • Requêtes ADO.NET paramétrées dans la DAL.
  • Vérification d’un emprunt actif et calcul du retard dans la BLL.

Apprentissage : distinguer la saisie utilisateur, les règles métier et l’accès aux données.

Évolution prévue : finaliser le branchement des formulaires et synchroniser les disponibilités. Le README décrit précisément les limites de la version d’origine.

05 / Développement C#

Vehicle Fleet Factory

Modéliser un parc automobile et comparer les comportements de véhicules à essence, électriques et hybrides.

C#WinForms.NET Framework 4.8XML
Explorer le projet et les apprentissages ↗

Objectif : gérer différents types de véhicules dans une application de bureau et appliquer la programmation orientée objet.

  • Classe abstraite Vehicle et trois classes spécialisées.
  • Interface IMileageEfficiency, héritage et polymorphisme.

Apprentissage : réutiliser un modèle commun et faire varier les calculs selon le véhicule.
